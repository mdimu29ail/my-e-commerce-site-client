# Design System

## 1. Visual Style
- **Theme:** Modern, clean, and user-friendly.
- **Primary Colors:** 
  - Primary: `#3B82F6` (Blue - default Tailwind)
  - Secondary: `#10B981` (Emerald)
  - Accent: `#F59E0B` (Amber)
- **Backgrounds:** Light mode (`#FFFFFF`) and Dark mode support (optional).

## 2. Typography
- **Font Family:** Inter or Sans-serif (via Tailwind).
- **Headings:** Bold, clear hierarchy.
- **Body Text:** Readable size (16px/1rem), good line height.

## 3. UI Components
- **Buttons:** Rounded corners, clear hover/active states.
- **Inputs:** Focused state highlights, clear error messages.
- **Cards:** Subtle shadows, consistent padding.
- **Modals:** Centered, backdrop blur.

## 4. Layout & Spacing
- **Grid/Flexbox:** Use Tailwind's grid and flex utilities.
- **Spacing:** Consistent margins and padding (using `p-4`, `m-2`, etc.).
- **Responsive:** Desktop first or Mobile first (ensure breakpoints for `sm`, `md`, `lg`, `xl`).

## 5. Icons
- Use **Lucide React** or a similar SVG icon library for consistency.
